## Angular workspaces (angular plugin)

In an Angular workspace, read `angular-implementation-guide.md` in your
knowledge before you plan or generate code. Respect the plan's change impact
map: Reuse-zone files are imported, never edited; Append-only files only gain
lines. Select elements in tests by `data-ui-id` only.
